EJERCICIO 03 Login Vertical Clásico (Margin absoluto en Grid, sin librerías)
di.unidad2.ejercicio3
🎯 Concepto Clave: Login vertical puro WPF sin librerías externas. Posicionamiento con Margin absoluto en Grid plano. BorderThickness="0,0,0,1" para estilo subrayado. Hyperlink con NavigateUri para enlaces. Ventana alargada Height="800" Width="400".
Resumen de estudio: este ejercicio se corrige revisando la composición manual, la diferencia entre TextBox y PasswordBox y el uso adecuado de Hyperlink para los textos auxiliares.
1. Grid Plano con Margin Absoluto Sin RowDefinitions. Cada control tiene Margin="L,T,R,B" para posicionarlo manualmente en el Grid.
2. Subrayado con BorderThickness BorderThickness="0,0,0,1" dibuja solo el borde inferior del campo, creando el efecto de línea subrayada.
3. Hyperlink en TextBlock <Hyperlink NavigateUri="..."> dentro de un TextBlock crea un enlace de texto clicable sin botón.
🎨 Snippet Interfaz Crucial (MainWindow.xaml) XAML 
<!-- Ventana alargada vertical, sin librerías externas -->
<Window x:Class="di.unidad2.ejercicio3.MainWindow"
        Height="800" Width="400"
        WindowStartupLocation="CenterScreen">
    <Grid Background="White">

        <!-- Logo -->
        <Image Source="/recursos/logo.png"
               Margin="130,60,130,0" VerticalAlignment="Top"/>

        <!-- Campo email con solo borde inferior -->
        <TextBox BorderThickness="0,0,0,1"
                 Margin="40,220,40,0" VerticalAlignment="Top"
                 Height="35" FontSize="14"/>

        <!-- Campo password con solo borde inferior -->
        <PasswordBox BorderThickness="0,0,0,1"
                     Margin="40,280,40,0" VerticalAlignment="Top"
                     Height="35"/>

        <!-- Enlace "Forgot password" con Hyperlink -->
        <TextBlock Margin="40,330,40,0" VerticalAlignment="Top">
            <Hyperlink NavigateUri="http://example.com">Forgot password?</Hyperlink>
        </TextBlock>

        <!-- Botón Login -->
        <Button Content="LOG IN" Margin="40,380,40,0"
                VerticalAlignment="Top" Height="45"
                Background="#333" Foreground="White"/>

        <!-- Botones sociales: StackPanel Horizontal -->
        <StackPanel Margin="40,460,40,0" VerticalAlignment="Top">
            <Button Height="40" Margin="0,0,0,8">
                <StackPanel Orientation="Horizontal">
                    <Image Source="/recursos/google.png" Width="20"/>
                    <TextBlock Text="Continue with Google" Margin="8,0,0,0"/>
                </StackPanel>
            </Button>
        </StackPanel>

        <!-- Enlace "Create account" -->
        <TextBlock Margin="40,620,40,0" VerticalAlignment="Top"
                   HorizontalAlignment="Center">
            <Hyperlink NavigateUri="http://example.com">Create account</Hyperlink>
        </TextBlock>
    </Grid>
</Window>

namespace di.unidad2.ejercicio3
{
    // SIN librerías externas → hereda de Window
    // SIN eventos → solo InitializeComponent
    public partial class MainWindow : Window
    {
        public MainWindow()
        {
            InitializeComponent();
        }
        // No hay eventos adicionales.
        // El Hyperlink navega por sí solo
        // si se añade RequestNavigate handler.
    }
}

<Application.Resources>
    <!-- VACÍO: sin MergedDictionaries -->

⚠️ Posibles Trampas de Examen (Ejercicio 3)
  • Grid sin RowDefinitions: El posicionamiento es con Margin absoluto, no con filas. Si añades RowDefinitions y Grid.Row, los controles se apilan todos en fila 0.
  • BorderThickness="0,0,0,1" exacto: El orden es Izquierda, Arriba, Derecha, Abajo. Si pones "0,1,0,0" el borde aparece arriba, no abajo.
  • Hyperlink dentro de TextBlock: <Hyperlink> no es un control independiente; debe estar siempre dentro de un <TextBlock> o similar (Inline).
  • App.Resources vacío: Este ejercicio NO usa MahApps ni Material Design. Añadir MergedDictionaries sin las librerías NuGet instaladas causa XamlParseException.

EJERCICIO 04 Login Discord (MetroWindow sin barra de título visible)
di.unidad2.ejercicio4
🎯 Concepto Clave: mah:MetroWindow con barra de título completamente oculta mediante ShowTitleBar="False" ShowCloseButton="False" ShowMaxRestoreButton="False" ShowMinButton="False". Grid 2 columnas: imagen | formulario oscuro Width="260".
1. MetroWindow Sin Barra Cuatro propiedades Show*="False" ocultan completamente la chrome bar de MahApps manteniendo funcionalidad Metro.
2. Layout 4* | Auto Grid con columna imagen proporcional (4*) y columna formulario de ancho fijo Auto con Width="260".
3. Acciones como TextBlock "Forgot Password" y "Sign Up" son TextBlock con Cursor="Hand", no botones, para aspecto minimalista Discord.
🎨 Snippet Interfaz Crucial (MainWindow.xaml) XAML 
<!-- App.xaml: MahApps Dark.Cobalt cargado -->
<ResourceDictionary.MergedDictionaries>
    <ResourceDictionary Source="pack://application:,,,/MahApps.Metro;component/Styles/Controls.xaml"/>
    <ResourceDictionary Source="pack://application:,,,/MahApps.Metro;component/Styles/Fonts.xaml"/>
    <ResourceDictionary Source="pack://application:,,,/MahApps.Metro;component/Styles/Themes/Dark.Cobalt.xaml"/>
</ResourceDictionary.MergedDictionaries>

<!-- MainWindow.xaml: MetroWindow sin barra visible -->
<mah:MetroWindow x:Class="di.unidad2.ejercicio4.MainWindow"
    xmlns:mah="http://metro.mahapps.com/winfx/xaml/controls"
    ShowTitleBar="False" ShowCloseButton="False"
    ShowMaxRestoreButton="False" ShowMinButton="False"
    Height="500" Width="800">

    <Grid>
        <Grid.ColumnDefinitions>
            <ColumnDefinition Width="4*"/>  <!-- Imagen -->
            <ColumnDefinition Width="Auto"/> <!-- Formulario -->
        </Grid.ColumnDefinitions>

        <Image Source="/recursos/bg.jpg" Stretch="UniformToFill"/>

        <!-- Panel formulario oscuro fijo -->
        <Grid Grid.Column="1" Width="260" Background="#2c2f33">
            <Grid.RowDefinitions>
                <RowDefinition Height="Auto"/> <!-- Contenido -->
                <RowDefinition Height="*"/>    <!-- Pie -->
            </Grid.RowDefinitions>

            <StackPanel Margin="24,40,24,0">
                <TextBox x:Name="txtEmail" Foreground="White"/>
                <PasswordBox x:Name="txtPass" Foreground="White"/>

                <!-- Botón Login color Discord -->
                <Button Content="Log In"
                        Background="#5865F2" Foreground="White"
                        Height="44" Margin="0,16,0,0"/>

                <!-- Acciones como TextBlock con Cursor=Hand -->
                <TextBlock Text="Forgot your password?" Cursor="Hand"
                           Foreground="#00AFF4" Margin="0,12,0,0"/>
                <TextBlock Text="Sign Up" Cursor="Hand"
                           Foreground="#00AFF4"/>
            </StackPanel>
        </Grid>
    </Grid>
</mah:MetroWindow>
⚡ Snippet Lógica Detrás (MainWindow.xaml.cs) C# 
// IMPORTAR MahApps: obligatorio
using MahApps.Metro.Controls;
using System.Windows;

namespace di.unidad2.ejercicio4
{
    // XAML usa <mah:MetroWindow>
    // → C# DEBE heredar MetroWindow
    // → NO Window (error de compilación)
    public partial class MainWindow
        : MetroWindow
    {
        public MainWindow()
        {
            InitializeComponent();
        }
        // Solo InitializeComponent()
        // No hay eventos definidos
    }
}

// RESUMEN SHOW* = FALSE:
// ShowTitleBar     → oculta barra
// ShowCloseButton  → oculta [X]
// ShowMaxRestore.. → oculta [□]
// ShowMinButton    → oculta [−]
⚠️ Posibles Trampas de Examen (Ejercicio 4)
  • ShowTitleBar="False" no funciona con Window: Esta propiedad es exclusiva de mah:MetroWindow. Ponerla en un <Window> estándar no tiene efecto.
  • Herencia en C#: Al usar <mah:MetroWindow> en XAML, el code-behind DEBE ser : MetroWindow, no : Window. Error de compilación garantizado si no coinciden.
  • Olvidar los 3 diccionarios MahApps: Controls, Fonts y Themes (Dark.Cobalt) son los tres obligatorios en App.xaml para que MetroWindow funcione.
  • Cursor="Hand" en TextBlock: No es una propiedad de UIElement sino de FrameworkElement. Siempre que se use TextBlock como enlace visual debe tener Cursor="Hand".
