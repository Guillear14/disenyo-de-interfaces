EJERCICIO 05 Login Material Design (BundledTheme + TextBox redondeados + FAB)
di.unidad2.ejercicio5
🎯 Concepto Clave: WindowStyle="None" + MaterialDesign BundledTheme (versión 5+, sin MergedDictionaries adicionales). TextBox redondeados con TextFieldCornerRadius="25". Botones FAB flotantes con MaterialDesignFloatingActionMiniLightButton y mat:PackIcon.
Resumen de estudio: esta práctica se resuelve identificando el esquema visual moderno: ventana sin marco, textos redondeados, iconos vectoriales del tema y ausencia de lógica pesada en code-behind.
1. BundledTheme en App.xaml Material Design v5+ usa <materialDesign:BundledTheme> que sustituye a los 3 MergedDictionaries anteriores en un solo elemento.
2. TextBox Redondeado Style="MaterialDesignOutlinedTextBox" con mat:TextFieldAssist.TextFieldCornerRadius="25" crea el efecto pildora.
3. Botones FAB Sociales Style="MaterialDesignFloatingActionMiniLightButton" con mat:PackIcon Kind="Facebook" crea los botones circulares flotantes.
🎨 Snippet Interfaz Crucial (App.xaml & MainWindow.xaml) XAML 
<!-- App.xaml: BundledTheme (Material Design v5+) -->
<!-- SIN MergedDictionaries adicionales -->
<Application.Resources>
    <ResourceDictionary>
        <ResourceDictionary.MergedDictionaries>
            <materialDesign:BundledTheme
                BaseTheme="Light"
                PrimaryColor="Red"
                SecondaryColor="DeepOrange"/>
            <ResourceDictionary
                Source="pack://application:,,,/MaterialDesignThemes.Wpf;component/Themes/MaterialDesign3.Defaults.xaml"/>
        </ResourceDictionary.MergedDictionaries>
    </ResourceDictionary>
</Application.Resources>

<!-- MainWindow.xaml -->
<Window
    WindowStyle="None" ResizeMode="NoResize"
    ShowInTaskbar="False"
    Height="500" Width="800">
    <Grid>
        <Grid.ColumnDefinitions>
            <ColumnDefinition Width="5*"/> <!-- Formulario -->
            <ColumnDefinition Width="5*"/> <!-- Imagen -->
        </Grid.ColumnDefinitions>

        <!-- TextBox redondeado con HintAssist -->
        <TextBox
            Style="{DynamicResource MaterialDesignOutlinedTextBox}"
            mat:TextFieldAssist.TextFieldCornerRadius="25">
            <mat:HintAssist.Hint>
                <StackPanel Orientation="Horizontal">
                    <mat:PackIcon Kind="Email"/>
                    <TextBlock Text="Email" Margin="4,0,0,0"/>
                </StackPanel>
            </mat:HintAssist.Hint>
        </TextBox>

        <!-- Botones FAB sociales -->
        <StackPanel Orientation="Horizontal">
            <Button
                Style="{DynamicResource MaterialDesignFloatingActionMiniLightButton}">
                <mat:PackIcon Kind="Facebook"/>
            </Button>
            <Button
                Style="{DynamicResource MaterialDesignFloatingActionMiniLightButton}">
                <mat:PackIcon Kind="Twitter"/>
            </Button>
        </StackPanel>
    </Grid>
</Window>

⚠️ Posibles Trampas de Examen (Ejercicio 5)
  • BundledTheme reemplaza a los 3 MergedDictionaries: En Material Design v5+, BundledTheme sustituye completamente a MaterialDesignTheme.xaml, MaterialDesignPalette.xaml y MaterialDesignColor.xxx.xaml. No usar ambos.
  • Herencia sigue siendo : Window: Material Design no cambia la herencia de la ventana. Solo MahApps obliga a usar MetroWindow. Con Material Design puro, se mantiene : Window.
  • ShowInTaskbar="False" con WindowStyle="None": Si la ventana no tiene barra de tareas y tampoco barra de título, no hay forma nativa de cerrarla sin un botón programado.
  • HintAssist.Hint con StackPanel: El hint puede ser un control complejo (StackPanel con PackIcon + TextBlock), no solo texto. Siempre va como propiedad adjunta mat:HintAssist.Hint.

EJERCICIO 06 Login Esquinas Redondeadas (Border + CornerRadius + OpacityMask)
di.unidad2.ejercicio6
🎯 Concepto Clave: Ventana con esquinas redondeadas: AllowsTransparency="True" + Background="Transparent" + Border CornerRadius="50". Imagen recortada con OpacityMask y VisualBrush Visual="{Binding ElementName=Mask}" donde Mask es un Border con CornerRadius asimétrico.
Resumen de estudio: el truco principal es la transparencia de la ventana y el recorte del contenido mediante un Border máscara; si se omite cualquiera de esos pasos, la forma redondeada no se demuestra.
1. Ventana Transparente WindowStyle="None" + AllowsTransparency="True" + Background="Transparent" hacen que el fondo del escritorio sea visible.
2. Border como Marco Redondeado Un Border CornerRadius="50" con Grid.ColumnSpan="2" actúa como fondo blanco de toda la ventana con esquinas recortadas.
3. OpacityMask para Imagen Image.OpacityMask con VisualBrush apuntando a un Border Name="Mask" recorta la imagen con las mismas esquinas del borde.
🎨 Snippet Interfaz Crucial (MainWindow.xaml) XAML 
<!-- Ventana transparente con esquinas redondeadas -->
<Window
    WindowStyle="None"
    AllowsTransparency="True"
    Background="Transparent"
    Height="500" Width="800">

    <Grid>
        <Grid.ColumnDefinitions>
            <ColumnDefinition Width="*"/>
            <ColumnDefinition Width="*"/>
        </Grid.ColumnDefinitions>

        <!-- Fondo blanco con esquinas redondeadas -->
        <Border CornerRadius="50"
                Grid.ColumnSpan="2"
                Background="White"/>

        <!-- Máscara invisible para recortar imagen -->
        <Border Name="Mask"
                CornerRadius="50 0 0 50"
                Background="White"
                Visibility="Hidden"/>

        <!-- Imagen recortada con OpacityMask -->
        <Image Source="/recursos/bg.jpg"
               Stretch="UniformToFill">
            <Image.OpacityMask>
                <VisualBrush
                    Visual="{Binding ElementName=Mask}"/>
            </Image.OpacityMask>
        </Image>

        <!-- Formulario con HintAssist -->
        <StackPanel Grid.Column="1" Margin="30">
            <TextBox
                mat:HintAssist.Hint="Email"
                Margin="0,0,0,12"/>
            <PasswordBox
                mat:HintAssist.Hint="Password"/>
        </StackPanel>
    </Grid>
</Window>

// BaseTheme="Light"

// CLAVE OpacityMask:
// 1. Border Name="Mask" Visibility=Hidden
// 2. Image.OpacityMask → VisualBrush
//    Visual={Binding ElementName=Mask}
// 3. La imagen queda recortada con
//    la forma del Border "Mask"

// CornerRadius="50 0 0 50"
// = TopLeft TopRight BotRight BotLeft
// Solo redondea lado izquierdo
⚠️ Posibles Trampas de Examen (Ejercicio 6)
  • OpacityMask requiere AllowsTransparency="True": Sin esta propiedad en la Window, el recorte de OpacityMask no funciona. Es el trío obligatorio: WindowStyle="None" + AllowsTransparency="True" + Background="Transparent".
  • El Border "Mask" debe ser Visibility="Hidden", NO Collapsed": Si se usa Collapsed, el VisualBrush no puede renderizarlo y la imagen queda sin recortar. Hidden mantiene el elemento en el árbol visual.
  • Orden de CornerRadius: "50 0 0 50" = TopLeft TopRight BottomRight BottomLeft. Para redondear solo el lado izquierdo, los valores izquierdos (TopLeft y BottomLeft) son 50.
  • Grid.ColumnSpan en el Border fondo: El Border blanco de fondo debe tener Grid.ColumnSpan="2" para cubrir ambas columnas del Grid, o quedará solo en la primera.
